# Guidance for agents contributing to UniHomelabDash

Start with the repository root [AGENTS.md](../../AGENTS.md), then [ROADMAP.md](../../ROADMAP.md) and [ARCHITECTURE.md](../../ARCHITECTURE.md). Root `AGENTS.md` stays canonical. This directory does not replace or publish it.

Publishable guides stay in [`site/src/content/docs/`](../../site/src/content/docs/). Register each page in [`docs/manifest.json`](../manifest.json) and keep the existing slug. Historical execution plans live in [`docs/internal/`](../internal/).

Do not add agent instructions or internal plans to the Starlight tree or the publication manifest.
