UniHomelabDash brings services, container status, health checks, logs, and safe
everyday actions into one calm interface. It is a **self-hosted**,
**mobile-first** Progressive Web App designed for private homelab networks.

Start with manual service links and on-demand health checks. When you are ready,
connect Docker or Portainer through the server-side provider system. Credentials
never need to enter browser storage, and disruptive actions stay opt-in with
confirmation prompts.

## Start here

Follow the [Docker quick start](./docker-quick-start/) to create a secret, start
the Compose stack, and create your first admin account.

## What is available today

- Manual service links, categories, hosts, notes, and health URLs
- On-demand health checks and attention-first service cards
- Multiple Docker connections through local socket, TCP, or TLS
- Container status, filtering, logs, and opt-in start/stop/restart actions
- Read-only Portainer endpoint, container, and log access
- Installable PWA experience for phones, tablets, and desktops

Features such as Portainer stacks, alerts, notifications, Proxmox, and AI
assistance remain roadmap work. The documentation labels planned capabilities
clearly so you can rely on every feature described as available.
