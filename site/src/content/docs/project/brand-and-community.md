UniHomelabDash should feel like a calm instrument panel: technical without
becoming overwhelming, modern without looking disposable, and comfortable on a
phone.

## Identity

- **Control Rail** is the primary icon.
- Charcoal carries most surfaces.
- Ruby marks active controls and brand emphasis.
- Burgundy adds depth without becoming a second accent family.
- Use the full UniHomelabDash wordmark when space allows.
- Avoid sci-fi typefaces, gradients on the logo, glowing server racks, and
  generic blue “homelab” branding.

Source SVGs, palette values, and usage rules live in
[`docs/branding`](https://github.com/uniskela/UniHomelabDash/tree/main/docs/branding).

## Join the project

- [Star or watch the repository](https://github.com/uniskela/UniHomelabDash)
- [Open an issue](https://github.com/uniskela/UniHomelabDash/issues) for a bug
  or scoped feature idea
- Improve a guide or screenshot
- Review an open pull request
- Propose a read-only provider with a clear security model

If the project saves you time and you want to support future releases, you can
[buy the maintainer a coffee](https://buymeacoffee.com/uniskela). Sponsorship is
always optional; code, feedback, testing, and documentation matter just as much.
